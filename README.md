# Inclusive Media Interfaces

Guidance for inclusive audiovisual interfaces and media control across televisions, streaming services, playback interfaces, access services, and relevant physical or connected products.

## Purpose and scope

This repository helps teams design how people discover, configure, navigate, and control audiovisual services and products connected to those experiences. It covers the interface journey and the physical or connected controls where they support media access, independent use, and integration with assistive or environmental systems.

It is for product and UX designers, researchers, broadcasters, streaming providers, platform teams, engineers, assistive-technology specialists, and AI agents working under human authority.

This repository concerns interface and control experiences. Accessible media production and caption/subtitle authoring belong to specialist sources. This repository does not decide legal applicability or establish compliance or conformance.

## Evidence, terminology, and limits

Use [Terminology and Principles](https://github.com/Double-FW/Terminology-and-Principles), beginning with [its current position](https://github.com/Double-FW/Terminology-and-Principles/blob/main/START_HERE.md), for term scope and status. Entries have individual review states; do not assume every glossary entry is adopted.

Keep access-service availability distinct from whether a person can discover, select, activate, and successfully use the service. Keep source-based claims, participant reports, observed behaviour, technical inspection, interpretation, and untested recommendations separate. Do not infer a single preference for a disability group. Synthetic personas, generated scenarios, and agent reviews can help formulate questions; they are not research with disabled people.

The guides describe design aims and questions to evaluate. They do not establish that a product is accessible, tested, or legally conformant. Use applicable standards and legal sources for those assessments, with appropriate evidence and accountable human review.

## Source and migration note

The media-interface guidance was consolidated from [Connected_TV.md](https://github.com/Double-FW/Inclusive_and_Effective_Design/blob/main/Connected_TV.md) and [Accessible_Interactive_Media_Control.md](https://github.com/Double-FW/Inclusive_and_Effective_Design/blob/main/Accessible_Interactive_Media_Control.md) in Inclusive and Effective Design. Those public paths now serve as migration pointers to the canonical guides here. The original interactive-media guidance was split into media interaction and physical/connected product-control modules to keep distinct material discoverable without repeating the TV-specific guide.

Use this repository for future media-interface updates and preserve source provenance when revising consolidated material. Linked and quoted source content remains subject to its own attribution and licence terms; this repository’s MIT licence does not change those terms.

## Hugging Face dataset sync

The repository is the authoring source for the [Inclusive Media Interfaces dataset](https://huggingface.co/datasets/GarethFW/Inclusive_Media_Interfaces). A curated export provides complete guidance documents and heading-level sections with source revision metadata. The two views overlap by design.

GitHub Actions syncs approved changes from the default branch weekly and after changes to the curated files. See [huggingface/SETUP.md](huggingface/SETUP.md) for token setup, scope, and workflow details. The Hugging Face dataset is a derived copy; GitHub remains the source of truth.
